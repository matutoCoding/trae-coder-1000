## 1. 产品概述
强制隔离戒毒所管理Web系统，服务于戒毒所民警，用于全流程管理戒毒人员从收治登记到解除回归的完整戒治周期。系统覆盖人员信息管理、医疗戒治、心理干预、体能康复、所内管控、教育帮扶及后续衔接七大核心业务场景，实现戒毒工作数字化、规范化管理。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 所领导 | 系统分配 | 全局数据查看、统计报表、审批管理 |
| 管教民警 | 系统分配 | 人员管理、日常管控、违规处理、会见安排 |
| 医疗民警 | 系统分配 | 体检评估、生理脱毒治疗、尿检筛查 |
| 心理民警 | 系统分配 | 心理咨询、心理矫治、心理评估 |
| 康复民警 | 系统分配 | 康复训练、体能测试、技能培训 |

### 2.2 功能模块
1. **人员收治**：戒毒人员收治登记、入所体检评估
2. **生理脱毒**：生理脱毒治疗记录、尿检复吸筛查
3. **心理矫治**：心理咨询记录、心理矫治方案、心理评估报告
4. **康复训练**：康复体能训练、体能测试记录、训练进度
5. **所内管理**：所内分级管理、违规违纪处理、亲情会见安排
6. **教育帮扶**：技能培训帮扶、教育学习记录、社会帮教
7. **解除回归**：期满解除登记、后续照管衔接、出所评估

## 3. 核心流程
戒毒人员从入所到出所的全流程管理：首先进行收治登记和入所体检评估，随后进入生理脱毒阶段，期间配合心理矫治和康复训练，在整个戒治周期内接受所内分级管理和教育帮扶，最终按期解除并完成后续照管衔接。

```mermaid

    A["收治登记"] --> B["入所体检评估"]
    B --> C["生理脱毒治疗"]
    C --> D["心理矫治干预"]
    D --> E["康复体能训练"]
    E --> F["所内分级管理"]
    F --> G["教育技能帮扶"]
    G --> H["期满解除登记"]
    H --> I["后续照管衔接"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深海蓝 (#1e40af) 象征专业与权威，搭配警徽蓝 (#1e3a8a) 作为强调色
- **辅助色**：墨绿 (#065f46) 代表健康与希望，橙红 (#dc2626) 用于预警提示
- **中性色**：浅灰蓝背景 (#f1f5f9)，深灰文字 (#1e293b)，白色卡片 (#ffffff)
- **按钮风格**：直角微圆角(4px)，扁平化设计，悬浮时轻微上移并加深阴影
- **字体**：中文使用"思源宋体"体现庄重感，数字/英文使用"JetBrains Mono"保证清晰度
- **布局风格**：左侧导航栏 + 顶部信息栏 + 主内容区的经典政务后台布局，卡片式信息展示
- **图标风格**：使用线性风格图标，简洁专业，统一2px线条宽度

### 4.3 响应式
采用桌面优先设计，主显示区域最小宽度1280px，适配1920x1080及以上分辨率。在平板设备上可折叠左侧导航，关键数据表格支持横向滚动。

### 4.4 动效设计
- 页面切换采用淡入上滑动画，时长300ms
- 卡片悬浮时轻微上移(translateY(-2px))并增加阴影
- 数据加载时使用骨架屏占位
- 状态变更时使用脉冲动画提示
- 图表数据采用渐进式绘制动画
